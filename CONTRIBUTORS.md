# Contributors and repository evidence

This file exists so that the commit history shows **distributed work**, which the brief
asks for ("commit history shows distributed work", §9.3, 5 marks).

## How to use it

Each member should, **from their own machine and with their own git identity**, add one row
to the table below and commit it. That gives the repository a commit authored by each
person, and the row names what that person actually did.

```bash
git config user.name  "Given Family"
git config user.email "your.qmul.email@se22.qmul.ac.uk"
# edit this file, add your row
git add CONTRIBUTORS.md
git commit -m "Add <name> to contributors"
git push
```

Do not rewrite or force-push; the history is part of the evidence.

## What the marker can check here

* every number and figure is regenerated by `python reproduce.py` from `data/` only;
* `outputs/<dataset>/results.json` follows the supplied schema;
* `docs/ai_usage_log.md` records the tools used and `docs/ai_error_ledger.md` the errors found;
* `docs/contribution_statement.md` is the signed version that accompanies the submission.

The data in `data/regular_G15` and `data/blind_G15` are the group's own issued datasets;
`manifest.json` records their SHA-256 checksums and the repository is configured to keep
them byte-identical across a checkout.
